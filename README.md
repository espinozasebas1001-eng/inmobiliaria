# Raíces Inmobiliaria

Sitio web responsive para una inmobiliaria, desarrollado como proyecto final de desarrollo web.

El sitio permite visualizar propiedades, consultar sus características, conocer información sobre la inmobiliaria y solicitar visitas.

## Tecnologías utilizadas

- HTML5
- CSS3
- SCSS
- Bootstrap 5.3.3
- Bootstrap Icons
- JavaScript
- AOS (Animate On Scroll)
- Git y GitHub
- Vercel

## Características del proyecto

- Estructura HTML semántica.
- Diseño responsive para mobile, tablet y desktop.
- Navbar responsive desarrollada con Bootstrap.
- Estilos organizados mediante arquitectura SCSS.
- Uso de variables, nesting, mixins, `@extend` y partials.
- CSS compilado ubicado en la carpeta `styles/`.
- Animaciones nativas mediante SCSS.
- Animaciones mediante la librería AOS.
- Galería de imágenes interactiva para las propiedades.
- SEO básico mediante títulos y meta etiquetas.
- Atributos `alt` en las imágenes.
- Organización de archivos y recursos multimedia.
